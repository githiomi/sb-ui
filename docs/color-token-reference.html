SB UI color token reference

This page renders the visual swatches for the tokens generated from packages/assets/colors.ts. It is easier to inspect than the Markdown version because browsers reliably render the CSS colors here.

Looking for bg-primary-500?

It is #00829d, generated as 0 130 157. Visually, it is the main brand teal.

How to use this page

Open this file directly in a browser. The Markdown preview may hide swatches, but this HTML file uses normal CSS backgrounds.

File: docs/color-token-reference.html

Primitive colors

These tokens do not change between light and dark mode. Each token is available in Tailwind as bg-..., text-..., border-..., and opacity variants such as bg-primary-500/20.

Semantic colors

Semantic tokens are theme-aware aliases. Prefer these for app surfaces, text, canvas backgrounds, and outlines.

Opacity tokens

These are defined in colors.ts, but they are not emitted as standalone CSS variables in dist/styles.css. They are shown here on a checkerboard so the alpha is visible.

Important notes

Topic What it means
rgba(...) source tokens The current toRgbTuple() converter keeps only RGB channels. For example, rgba(112,112,112,0.2) becomes 112 112 112. Use a Tailwind opacity suffix such as border-outline/20 when you want the alpha.
--color-secondary This appears in generated CSS from Tooltip.tsx, but it is not generated in :root. It only works if a consumer app defines that CSS variable separately.
.text-[a-zA-Z0-9-] This is Tailwind scanner noise from a regex-like string in Tooltip.tsx. It is not a real color token.
